# P009 技能升级

- 比赛：校外实训（二）-大三实习（蔡炳跃）班
- 题型：OI
- 难度：Mid
- 语言：C, C++, Java, Python3

## 题目描述

<p>小蓝最近在玩一款 RPG 游戏。</p><p>他的角色一共有 N 个可以放攻击力的技能。</p><p>其中第 i 个技能首次升级可以提升 Aᵢ 点攻击力，以后每次升级都会点数会减少 Bᵢ。</p><p>「合」（上取整）次后，再升级该技能将不会改变攻击力。</p><p>现在小蓝可以总升级 M 次技能，他可以任意选择升级的技能和次数。</p><p>请你计算小蓝最多可以提高多少点攻击力？</p>

## 输入描述

<p>输入第一行包含两个整数 N 和 M。</p><p>以下 N 行每行包含两个整数 Aᵢ 和 Bᵢ。</p>

## 输出描述

<p>输出一行包含一个整数表示答案。</p>

## 样例

### 样例 1

#### 输入

```text
3 6
10 5
9 2
8 1
```

#### 输出

```text
47
```

## 提示

<p><strong>数据范围</strong></p><p>对于 40% 的评测用例，1 ≤ N, M ≤ 1000；</p><p>对于 60% 的评测用例，1 ≤ N ≤ 10⁴，1 ≤ M ≤ 10⁷；</p><p>对于所有评测用例，1 ≤ N ≤ 10⁵，1 ≤ M ≤ 2 × 10⁹，1 ≤ Aᵢ, Bᵢ ≤ 10⁶。</p><p><a href="https://www.acwing.com/video/4594/" target="_blank">Y总讲解</a></p><p><a href="https://www.acwing.com/problem/content/4659/" target="_blank">原题链接</a></p>
