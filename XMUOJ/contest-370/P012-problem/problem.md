# P012 孤独的照片

- 比赛：校外实训（二）-大三实习（蔡炳跃）班
- 题型：OI
- 难度：Mid
- 语言：C, C++, Java, Python3

## 题目描述

<p>Farmer John 最近购入了 N 头奶牛的奶牛，每头奶牛的品种是更赛牛（Guernsey）或荷斯坦牛（Holstein）之一。</p><p>奶牛自然排成一排，Farmer John 想要为它们拍摄不少于三头奶牛的团体照片。</p><p>然而，他不想拍摄这样的照片，其中只有一头奶牛是更赛牛或荷斯坦牛。或者只有一头荷斯坦牛在其中为这种奶牛拍照是很难的。</p><p>在奶牛这样排成不少于三头奶牛的序列中，他称其中有一头更赛牛或荷斯坦牛的照片，即其中只有一头更赛牛或荷斯坦牛的照片。</p><p>给定奶牛的排列方式，请帮助 Farmer John 决定他可以拍摄多少张少孤独的照片。</p><p>如果两张照片以不同的奶牛开始或结束，则认为它们是不同的。</p>

## 输入描述

<p>输入的第一行包含 N。</p><p>输入的第二行包含一个长为 N 的字符串，如果第i位上的奶牛头是更赛牛，则字符串第 i 个字符为 G ，否则为第i个字符为 H 。</p><h4>数据范围</h4><p>3≤N≤5×10^5</p>

## 输出描述

<p>输出 Farmer John 会拍摄的照片的照片数量。</p>

## 样例

### 样例 1

#### 输入

```text
5
GHGHG
```

#### 输出

```text
3
```

## 提示

<p style="margin-left: 0px;">样例解释</p><p>这个例子中的每一个长为 3 的子串的拍照都会一头更赛牛或荷斯坦牛一一所以这样子照片表示孤独的照片，并会被 Farmer John 拍摄。</p><p>所有更长的子串（GHGH、HGHG和GHGHG）都可以被接受。</p><p><a href="https://www.acwing.com/problem/content/4264/" target="_blank">原题链接</a></p><p><a href="https://www.acwing.com/video/5345/" target="_blank">Y总讲解</a></p>
