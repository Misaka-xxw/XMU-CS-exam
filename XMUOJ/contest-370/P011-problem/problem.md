# P011 三国游戏

- 比赛：校外实训（二）-大三实习（蔡炳跃）班
- 题型：OI
- 难度：Mid
- 语言：C, C++, Java, Python3

## 题目描述

<p>小蓝正在玩一款游戏。</p><p>游戏中魏蜀吴三个国家各自拥有一定数量的士兵 X,Y,Z（一开始可以认为都为 0）。</p><p>游戏有 n 个可能会发生的事件，每个事件之间相互独立且最多只会发生一次，当第 i 个事件发生时会分别让 X,Y,Z 增加 Ai,Bi,Ci。</p><p>当游戏结束时 (所有事件的发生与否已经确定)，如果 X,Y,Z 的其中一个大于另外两个之和，我们认为其获胜。</p><p>例如，当 X&gt;Y+Z 时，我们认为魏国获胜。</p><p>小蓝想知道游戏结束时如果有其中一个国家获胜，最多发生了多少个事件?</p><p>如果不存在任何能让某国获胜的情况，请输出 −1。</p>

## 输入描述

<p>输入的第一行包含一个整数 n。</p><p>第二行包含 n 个整数表示 Ai，相邻整数之间使用一个空格分隔。</p><p>第三行包含 n 个整数表示 Bi，相邻整数之间使用一个空格分隔。</p><p>第四行包含 n 个整数表示 Ci，相邻整数之间使用一个空格分隔。</p>

## 输出描述

<p>输出一行包含一个整数表示答案。</p><p style="margin-left: 0px;">数据范围：</p><p style="margin-left: 0px;">对于 40% 的评测用例，n≤500；对于 70% 的评测用例，n≤5000；对于所有评测用例，1≤n≤10^5，0≤Ai,Bi,Ci≤10^9。</p><p>样例解释：发生两个事件时，有两种不同的情况会出现获胜方。发生 1,2 事件时蜀国获胜。发生 1,3 事件时吴国获胜。</p>

## 样例

### 样例 1

#### 输入

```text
3
1 2 2
2 3 2
1 0 7
```

#### 输出

```text
2
```
