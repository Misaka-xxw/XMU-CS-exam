##### ccf

全国CCF计算机软件能力认证考试中，按照考出的最高分：
+ 超过400分（含400分），加4分；
+ 超过320分（含320分），加3分；
+ 超过280分（含280分），加2分。

如果要考的话，找人打听一下“团购”优惠。
题目构成（5道题）：
1. 签到题
2. 算法基础题
3. 大模拟题（字符串等）
4. 算法困难题
5. ACM题

第三题代码量很大，也许，能用Python骗分（）

##### 竞赛
> [!TIP]
> 两个人参加竞赛拿分是最高的，比单人参赛要高！所以团队竞赛哪怕你喜欢单挑，也带上你的一个好朋友一起参赛！

解读一下加分文档：

| 项目     | 等级           | 基准分数 | A+类加权系数 | A类加权系数 | A-类加权系数 |
| :------- | :------------- | :------- | :----------- | :---------- | :----------- |
| 国家级   | 特等奖         | 9        | 2            | 1.5         | 1            |
|          | 一等奖         | 8        | 2            | 1.5         | 1            |
|          | 二等奖         | 4.5      | 2            | 1.5         | 1            |
|          | 三等奖         | 2.7      | 2            | 1.5         | 1            |
| 省级     | 一等奖及以上   | 2.4      | 2            | 1.5         | 1            |
|          | 二等奖         | 1.2      | 2            | 1.5         | 1            |

举例（以改计算方法的2022级为例）：
1. 小A参加蓝桥杯省赛Python赛道二等奖，蓝桥杯是A类竞赛，而且他参加的是个人赛，个人赛需要按照 1/3的权重进行计算。所以最终加分 = ```1.2×1.5×(1/3)=0.6```分
2. 小A**同年**不仅仅参加了Python，还去参加了隔壁蓝桥杯电子赛，但是只能按加分最高的一次算分。
3. 小A从大一到大三一直参加蓝桥杯，连着三年拿了省二，就加了三次0.6分。
4. 小B和小C两位一起参加了计算机设计大赛（A类），获得了省一和国二，按国二算，最终加分 = ```4.5×1.5×(1/2)=3.375```分

#### 课程学分转换
以2022级为参考：

1. **专业课转校选**
   + 建议大一第二学期修一门美育课，其它校选课可以用专业课转换
   + 和信院计算机相关的课无法转换成校选
   + 电院大一年级平转信院，校选课转换分很少（可能只有机械制图），需要另外修校选
   + <mark>转专业前选了信息学院开设的校选课，学分可能会无效</mark>
2. **数学课**
   + 转专业前修过《微积分Ⅰ》，为同一课程
   + 《线性代数Ⅰ》学分可以转成《线性代数A》免修，但是原绩点不计算。
   + 数学学院不知道。
3. **物理课**
   + 《大学物理A》上下都修完了，可以合并一起转换成《大学物理B》上下。不能上单独转换，也不能下单独转换。
   + 物理学院另说
4. **英语课**
   + 英语课全校通用
   + 英语专业另说
5. **电路原理**
   + 电院《电路分析》学分可以转成《电路原理》免修，但是原绩点不计算。
   + 修了航院等学院的《电路原理》，也不用修信院《电路原理》。
6. **C语言**
   + 只要不是信院的C语言，都不能转换。必须补修。
7. **新生研讨课与心理健康课**
   + 如果在原学院的新生研讨课合格了，就不用再修了。心理健康课同理。心理学分全校通用。

## 资源篇
### 图书馆
在 XMULibrary 微信公众服务号 上可以预约。
三楼D区的特色空间很适合线上笔试/面试。建议提前两天预约。

> [!TIP]
> 如何找到心仪的书？

可以先在 XMULibrary 资源检索-我的图书馆 中先搜索想借的书。会写好几楼几区，和书架的范围，并非按照数字序，而是按照“字典序”找书。

如果有人借了书，但是你很想看的话，可以提前预约等TA还书。
如果翔安没有的话，可以申请“馆际互借”，会有人把书从思明/漳州校区运过来，在图书馆前台领取。

推荐三楼C区有很多小说，~~三楼D区有漫画，~~ 四楼A区有数学相关的书，四楼C区有计算机相关的书 ~~，很适合摆在书架上做装饰~~ 。

五楼智慧空间可以玩魔方等益智玩具。

### 健身房
除了体育馆，益海嘉里楼五楼也有健身房，不用预约但是可能会没位置。有跑步机、乒乓球桌等设施。

### 游泳馆
要在规定时间内去学校的医务室办理健康证。提前预约，带校园卡、健康证去游。

### 乐器房
学生活动中心的乐器房在8:30到20:30开放，需要在厦门大学信息门户网站的“翔安校区学生活动中心”（或者微信小程序i厦大网上服务平台）内预约。
B102是古筝房，B103和B104是钢琴房。去琴房前要去办公室签到，工作人员带你过去。
乐器房蚊子很多，注意防蚊防暑。
